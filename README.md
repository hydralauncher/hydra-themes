# Adwaita Hydra

An Adwaita-inspired theme for [Hydra Launcher](https://github.com/hydralauncher/hydra), designed to bring the visual language of GNOME and libadwaita to Hydra.

<img src="themes/Adwaita-JjKvJ6a5/screenshot.png" alt="Adwaita Hydra preview" width="700">

## Extended Installation with Minimize/Maximize Button Removal and Accent Color Customization

1. [Download `theme.css`](themes/Adwaita-JjKvJ6a5/theme.css).
2. Open Hydra Launcher.
3. Open **Settings → General → Appearance**.
4. Click **Create** and paste the contents of `theme.css`.
5. Follow the instructions provided after the description.

For the standard installation, use the [Theme Store](https://hydrathemes.shop/).

## Bug Reports

This theme is still being actively refined. If you encounter a visual issue, broken component, or an element that does not follow the Adwaita style, please [open an issue](https://github.com/kusaida/adwaita-hydra-theme/issues) and include a screenshot and, if possible, a description of the problem.
